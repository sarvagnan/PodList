# PodList Mac UI grade · Round 23 · Codex

## Frame

- **Task** — Find a podcast Episode, play it or put it in the right Playlist, and return to the queue and listening history later.
- **Target** — Native Mac app, SwiftUI with AppKit integration, macOS 26+, source at `a0ec64b`.
- **Era** — macOS 27.2 (26B123) in the VM, SDK and minimum OS 26.0, current build with no compatibility opt-out. Light and Dark selected inside the app. Reduce Transparency and Increase Contrast off in the captures. Show Borders on for the two dedicated strips. Glass tint and Reduce Motion were not reported.
- **Posture** — Sovereign personal library with background playback and a transient Now Playing window.
- **Audience** — Perpetual intermediate who listens regularly and curates multiple queues, with an accessible starting path for newcomers.
- **Nearest exemplar** — Things for quiet source lists, explicit attention to the selected item, and reversible edits. Apple Podcasts on macOS 27.2 is the platform comparison.
- **Character** — Compact, two-line Episode rows with trackable numerical columns. Saved Views and ordered Playlists share a shallow source list. Artwork and notes sit in a selection-linked Inspector. A restrained blue identity colors artwork placeholders and the Multicolor accent. Fixed owner decisions preserve the two-pane narrow layout and floating bottom player.

**Owner decisions.** The fixed behavior includes system accent outside Multicolor, Light/Dark/System, regular glass for the player and specified controls, and a noncustomizable toolbar. Below about 950 pt the Inspector opens explicitly and trades places with the sidebar. Sidebar recovery is deliberate. At wide sizes the Inspector follows selection unless turned off. Its divider is resizable and width is remembered. Playlist controls share one action group. Row, toolbar, and Inspector may each offer Play, while the bar transports current playback. Saved Views is the menu name. The Podcast page uses two clicks to unsubscribe, the menu and context routes unsubscribe directly, and both are undoable. The status Undo is scoped to the current screen, with global labeled Undo/Redo in Edit. Undo of a deleted View or empty Playlist names the restored item and retains the current destination. Subscription Settings leaves Mark All Played in the menus. Playlist Settings keeps the deleted Playlist and draft in view with Restore and Close. Timeline shows Rewind on the selected row and supplies the context, menu, and accessibility routes. The navigation and New Playlist timing misses are accepted. App Intents are on, Spotlight writes are confined to release and VM tour builds, Shortcuts donations are release-only, and MCP is opt-in.

### Blockers

- **FLOW-03** — A sync can normalize or clear text while Edit View is still being edited. In the surface shown in 16, start with a seven-day filter and enter `007` in Last Days. The setter stores the raw string and parsing yields the same seven-day rule, so `update` returns without a pending or unapplied edit. A synced change to that View, such as a rename from another device, passes the clean-state test, calls `reconcileDraft()`, and clears the active numeric buffer. The field falls back to formatted `7`. The same reset is shared across the other numeric buffers, including ones unrelated to the synced change. The two sources are enough to establish the path. It was outside the delayed Undo probe in 44. Protect focused and locally modified buffers independently of the filter model, merge committed fields underneath, and reconcile only the field explicitly committed or abandoned. [ViewEditorScreen.swift](../../apps/apple/Sources/PodListUI/ViewEditorScreen.swift#L169) · [FormNumbers.swift](../../apps/apple/Sources/PodListUI/FormNumbers.swift#L12)
- **DATA-01** — Cancel in Edit View can overwrite a saved change from another window or device. Edit a condition in window A so a live save is recorded. Save a rename for the same View in window B. Cancel A. The cancellation tests for any edit in A’s session and then saves the complete original View from A, including the old name, over B’s latest record. This differs from the safe Playlist Settings draft handling demonstrated in 11a. Stage the View edits until Save, or make live cancellation roll back only the fields and revisions written by that sheet. Exercise two windows editing one View as a regression. [ViewEditorScreen.swift](../../apps/apple/Sources/PodListUI/ViewEditorScreen.swift#L243) · [LibraryEditingModel.swift](../../apps/apple/Sources/PodListUI/LibraryEditingModel.swift#L186)
