## Frame

- **Task:** keep up with podcasts: find Episodes through saved Views, queue them into ordered Playlists, and play them, with Subscriptions managed alongside.
- **Target:** Mac app (SwiftUI, macOS 26+).
- **Era:** captured on macOS 27.2 in a VM (Retina, 1920 × 1200 pt); built with the macOS 26.0 SDK (minos 26.0, sdk 26.0), no `UIDesignRequiresCompatibility`, so a **current build**. Appearance forced Light and Dark through the app's own setting; Reduce Transparency and Increase Contrast off in every capture (their handling read from code). The system accent is the VM default (Multicolor), so the app's AccentColor (`#2B50C8` / `#3652D0`) is in effect in every capture.
- **Posture:** sovereign (a library window open all day, with transport always present).
- **Audience:** perpetual intermediate, with expert routes (menus, shortcuts, App Intents, MCP).
- **Nearest exemplar:** Things (calm personal tool, deliberate copy, forgiving), with BBEdit's ambition for a complete menu bar.
- **Character (signature elements):**
  1. Initials artwork tiles in a pale brand-blue square (`MH`, `DF`, `SB`) used everywhere artwork is missing: rows, Inspector, player, Now Playing.
  2. Dense four-column Episode tables (Episode / Published / Length / State) with a two-line title-and-podcast cell and quiet row actions that light up in the accent on hover or selection.
  3. Plain, consequence-first explanatory copy with capitalized domain nouns (Episode, Entry, Playlist, View, Device, Position) — "Rewind can be undone", "Deleted Playlists can be restored from Trash for 30 days".
  4. A full-width bottom glass player bar with ±15/30 transport, Speed and Sleep menus, and the Active Playlist with "N after current" (owner fixed).
  5. Brand blue as the Multicolor AccentColor (owner fixed).
- **Owner decisions recorded:** brand blue only as AccentColor (deep `#3652D0` in Dark, including the selected Settings tab label — graded, not a target); transport in a bottom player bar; Appearance setting with Light, Dark and follow macOS; no customizable toolbar; two-click arm/confirm Unsubscribe with undo; Liquid Glass on the player bar, Inspector actions, Now Playing and the footer of scrolling sheets; Spotlight/`podlist://`/Add to PodList Service implemented but not captured; MCP off by default, App Intents on.

Baseline: the captures in `mac-round-18/` are this round's baseline.

### Failures by severity

**Major**

- **[APPEAR-04] Dark Settings selected-tab label fails contrast (owner decision; cap stands).** In D/27–D/32 the selected toolbar pane label "General" is drawn by macOS in the app's Dark AccentColor on the selected pill: measured glyph `#435FDD` on `#484747` = **1.73:1** (needs 4.5:1; it's ~11 pt text and a control label, so the severity is major). The same label in Light measures 7.69:1 (L/27). Other measured text passes: secondary `#606060` on white 6.29:1, `#A0A0A0` on `#242222` 6.05:1, Dark "Current Entry"/"Show Description" `#9DB1FF` 7.66:1, Inspector placeholder 5.38:1 (L) / 5.70:1 (D); the player bar's title, subtitle and times over scrolled rows measure 14.0–20.7:1 (L/35–36) and 8.4–10.5:1 (D/35–36), though nothing bounds the worst case under that regular glass. Source: `apps/apple/Resources/MacAssets.xcassets` AccentColor Dark `#3652D0`; `MacAppearance.swift` documents the choice. **Fix (if the owner revisits):** keep `#3652D0` for the selected-row fill, but give the asset a Dark value that reaches 4.5:1 against the system's selected-pill gray (about `#7C93F5` or lighter), and keep white-on-fill row text readable by drawing emphasized selections in the existing `MacOnAccentStyle` rule. Owner-decided, so it isn't the next target.

**Minor**

- **[TYPE-06] Show notes in the Inspector run at about 31 characters a line at the default window size.** L/03 and D/03: "Who sets the price of rice?. An" is the first full line in a 1180 pt window; the ~270 pt Inspector leaves a ~230 pt text column. The "Show in Window" escape hatch exists (`EpisodeNotesWindow.swift`), but the default reading surface is below the 45-character floor. **Fix:** raise the Inspector's default width (`MacWindow.swift:205`, `inspectorColumnWidth(min: 260, ideal:…, max: 440)`) to ~350 pt and set show-notes text at `.callout` (12 pt) there; at the measured ~6.8 pt per character that gives ~45 characters a line.
- **[MENU-04] Title-style lapses in menu titles.** `menus.txt`: View › "Sort by" (Finder and Apple style use "Sort By"), Episode › "Play Now in", "Play Next in", "Play Last in" (a final preposition is capitalized in title style). Source: `MenuCommandActions.swift:174`, the `Play … in` submenus in `EpisodeEditingViews.swift`. **Fix:** "Sort By", "Play Now In ▸", "Play Next In ▸", "Play Last In ▸" (or "Play Now in Playlist ▸" if the lower-case form is preferred, as long as it's title style).
