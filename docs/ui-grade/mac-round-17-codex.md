## Frame

- **Task:** Find podcasts and Episodes, arrange Episodes as ordered Playlist Entries, and listen while preserving each Playlist’s Position, History and Listening Timeline.
- **Target:** Native **Mac app**, SwiftUI/AppKit, macOS 26+.
- **Era:** Captured on macOS **27.2**, 1920×1200 pt Retina desktop, 2× images; SDK **26.0**, minOS 26.0, no `UIDesignRequiresCompatibility` opt-out, therefore a **current build**. App-selected Light and Dark; Reduce Transparency and Increase Contrast off. Accessibility variants are inspected in code, not captured.
- **Posture:** Sovereign personal Library and listening tool, with transient discovery and task sheets.
- **Audience:** Perpetual intermediate; a newcomer must still understand View versus Playlist without learning the storage model.
- **Nearest exemplar:** Things for calm selection, readable rows, complete commands and reversible actions; BBEdit for a complete searchable command index. Comparison is about decisions and craft. Current-system references opened: [Mail 27.2](/Users/sarvagnan/Documents/UI_Guidelines/examples/screenshots/apple-reference/07-mail.png) and [Music 27.2, scrolled](/Users/sarvagnan/Documents/UI_Guidelines/examples/screenshots/apple-reference/20-music-radio-scrolled.png). PodList has the same current native source-list/toolbar grammar. Its dense Episode table is an appropriate domain choice; its collapsed minimum-width table is not.
- **Character:** Blue monogram artwork placeholders; quiet two-line Episode rows with tabular metadata; Views as saved conditions; Playlist-specific Entries/History/Timeline; persistent glass bottom transport. Baselines are the supplied paired captures, especially 02/03/06/18 and 35/36.

**Owner decisions:** Retain the bottom transport; Light/Dark/System choice; no customizable toolbar; two-click, disarmable and undoable unsubscribe; regular Liquid Glass on functional surfaces; brand AccentColor only under Multicolor (system accent otherwise); deep Dark accent; release/tour-only Spotlight and release-only donations; MCP off by default, App Intents available. These are scored normally. WIN-05 and the Dark Settings label’s APPEAR-04 failure are accepted decisions and excluded from improvement targets. SET-02 passes the current checklist’s explicit System-default allowance. APPEAR-02 passes; the brand is no longer a forced control tint.
