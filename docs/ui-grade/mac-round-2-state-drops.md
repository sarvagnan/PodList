# Mac round 2: restoration and Playlist drops

DATA-06 stores a stable top-visible row ID and its ordinal, independently of selection, plus the measured sidebar and Inspector widths in each window's existing SceneStorage archive. Existing archives without these fields remain readable. A deleted anchor falls back to the nearest surviving row in display order; an empty list drops the anchor. Podcast pages defer reconciliation until their feed read completes. Restoration only scrolls the native Table/List clip view and applies window-local layout state; it never invokes an edit or playback command.

DRAG-06 selects and reveals successful drop results when the destination's Entries are showing. Otherwise the window retains a pending selection until that Playlist's Entries are opened. Failed drops do not queue a selection.

DRAG-02 retains the existing same-Playlist reorder and cross-Playlist copy defaults. Option changes a same-Playlist reorder into a copy. Each Playlist permits only one Entry for an Episode, so copying an Entry into its own Playlist leaves it in place and selects it. Cross-Playlist drops always copy Episode references with the copy (+) cursor. Option does not change them: the domain has no cross-Playlist Entry move preserving source Position, History, cursor and Listening Timeline. Removing the source after adding the Episode would discard that per-Playlist context. Sidebar drops also remain Play Last copies with the + cursor.

PTR-01 reuses Restore in Trash row context menus. Delete Permanently requires confirmation and records the shared PurgePlaylist operation, removing only that Playlist's recovery data. It preserves live Playlists, Episode facts and the permanent Listening log. Stale undo/redo steps that would restore that Playlist are discarded. Swift, TypeScript and Kotlin reducers understand the operation, with a shared replay vector covering duplicate purges and attempts to purge live Playlists.

The Subscriptions bulk-rule button counts the intersection of the current selection and visible Subscription IDs. Select All remains native and works even when a section header participates in the List selection.
