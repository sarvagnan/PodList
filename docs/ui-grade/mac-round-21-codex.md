# PodList Mac UI grade · Round 21 · Codex

## Frame

- **Task** · Find Episodes from Subscriptions or saved Views, queue them in a Playlist, and listen and resume with the intended Entry and Position intact.
- **Target** · Native Mac app. SwiftUI with AppKit bridges for native window, table, input, and system behavior. Audited source `7997de0`.
- **Era** · Current build on macOS 27.2 (26B123), built with SDK 26.0, minimum macOS 26.0, with no compatibility opt-out. App Appearance set explicitly to Light and Dark. Reduce Transparency and Increase Contrast off in the tour. Show Borders on in the targeted second pass. Retina 2×, 1920 × 1200 pt display.
- **Posture** · Sovereign personal Library workspace, with background playback and a transient discovery panel.
- **Audience** · Perpetual intermediate. Subscribing and listening are useful immediately. Saved Views, per-Playlist positions, and Timeline Rewind reward repeated use.
- **Nearest exemplar** · Things 3 for a calm personal workspace, reversible edits, and a menu bar that indexes the visible app. Apple Podcasts on macOS 27.2 is the era and playback reference.
- **Character** · Compact, text-first Episode tables and an Inspector that follows selection in wide windows (owner fixed). Saved Views and ordered Playlists with separate History and Listening Timeline. Bottom glass playback strip and comparatively quiet toolbar (owner fixed). Brand-blue artwork placeholders and Multicolor accent asset (owner fixed).

**Owner decisions.** Grade the Multicolor-only accent, including the accepted dim Dark Settings pane label, the System/Light/Dark override, and glass on playback and editing chrome. Preserve the two-pane narrow policy, remembered Inspector width, grouped Playlist actions, fixed toolbar, and row/toolbar/Inspector Episode play routes. Preserve Saved Views naming, two-click armed Unsubscribe on the Podcast page and immediate undoable menu Unsubscribe, local status-row Undo and global Edit Undo, non-navigating Undo for deleted Views and empty Playlists, Subscription Settings scope, in-place deleted Playlist Settings and the selected-row Rewind action. The sidebar and New Playlist latency misses are accepted. The release conditions for Spotlight and donations and the default-off MCP server are intentional.
